# 工作台操作与浏览器诊断

> [English](workbench-ui.md)

## 设置草稿

带保存按钮的设置在提交前属于草稿。关闭设置或按 Escape 时，如果仍有未保存内容，会先提示；选择保留后，可以重新打开继续编辑。切到记忆中心也不会重置这些草稿。

草稿只保存在当前页面内存中，API Key 不会因为此功能写入 localStorage 或 sessionStorage。刷新、关闭浏览器页或离开站点时，浏览器会在存在未保存修改时提醒；浏览器限制可能影响提醒，因此离开前请先保存。已存在的文件编辑器离开提醒继续有效。

默认会话设置和 API Key 使用底部保存；Provider 编辑器、MCP、Hook 与记忆引擎使用各自的保存或添加按钮。保存一处不会替你提交其他区域的配置。默认设置、API Key、Provider 编辑和记忆引擎配置在保存请求期间继续输入的新内容，仍属于未保存草稿。

## 界面偏好

桌面浏览器与移动端 PWA 访问同一份工作文件和会话状态。界面支持亮色、暗色、护眼模式和自定义主题色，中英双语切换无需刷新。部分布局与显示偏好保存在当前浏览器，不属于跨设备同步的内容。移动端安装与通知配置见[手机端 PWA](mobile_zh.md)。

## 文件与会话入口

会话顶部的“更多工具”提供任务交付与环境、Skills、MCP、生成图片、定时任务与重新加载页面。全局命令面板继续支持快捷键与搜索入口。

没有打开文件时，预览区提供搜索、新建和上传入口；桌面可选择收起预览来专注会话。操作沿用现有布局偏好，不会在每次启动时重置用户选择。

- **文件管理**：支持拖拽上传、上传进度、模糊搜索、重命名与回收站。文件引用保留来源工作区，切换工作区不会改变引用目标。
- **编辑与预览**：支持 Markdown 编辑与分屏预览、页内查找、缩放、阅读位置恢复和 HTML 活动页面状态保留。
- **全局搜索**：统一检索文件名、文件内容、会话、历史消息和常用操作。
- **真实终端**：支持创建、重命名和切换 PTY 终端。每个终端绑定创建时的工作目录；Profile 和移动端操作见[终端](terminal_zh.md)。

## 连续的会话工作流

支持多会话标签和后台执行。切换标签不影响其他会话的回复；执行过程中提交的消息可进入持久队列，按顺序处理。发送回执、去重、取消与断线恢复的行为见[交互可靠性约定](ux-reliability_zh.md)。

- **会话分支**：通过“从这里 Fork”保留所选位置的历史，并在新会话中继续探索；原会话保持不变。
- **末轮重问**：使用回合操作区的“在新分支重试最后一轮”，在新分支重新发送最后一轮请求，而不是覆盖原来的回复。需要等待当前任务和后台任务结束；包含附件的回合应重新附加文件后发送。

工作区切换只改变当前视图和新会话的默认目录，已有会话与终端保留各自的工作目录。上下文与目录配置见[工作区说明](personalize-claude-md_zh.md)。

## 全局任务管理

全局任务中心集中展示不同会话的任务状态，包括运行中、失败及已完成待查看的任务。后台任务、Monitor 和活动记录可用于核对执行进度与结果；需要查看完整过程时，返回所属会话。

定时执行见[定时任务](scheduler_zh.md)。配置 Web Push 后可接收任务完成通知，配置方式见[手机端 PWA](mobile_zh.md)。

## 执行记录与配置入口

会话展示运行时提供的思考块、工具调用及结果、代码修改差异、嵌套子代理时间线和 Hook 执行状态；上下文用量、逐模型用量与回合耗时可用于检查本轮执行情况。可用记录取决于所选模型与运行时。

工具摘要和 Bash 标准输出、错误输出中的文件路径支持点击打开工作区预览，也支持引号内带空格或中文的路径。点击脚本路径会打开文件供查看，不会执行脚本。

设置中心提供模型和 Hook 配置，记忆管理与服务维护使用独立入口。模型接入见 [Providers](providers_zh.md)，扩展配置见 [Skills](skills_zh.md) 和[配置参考](configuration_zh.md)。

## 标注 HTML 元素

1. 打开当前工作目录中的 HTML 文件。
2. 点击预览工具栏中的“标注页面元素”。
3. 点击页面上的目标元素；高亮框表示选中的对象。
4. 输入简短修改意见，选择“加入会话引用”。

引用保留来源工作目录与文件绝对路径，并携带 CSS 定位、可见文本和评论。加入引用不会发送消息或修改文件；由你确认后再发送给 Agent。切换文件或工作目录会结束当前标注。

该功能仅用于 MuseLab 提供桥接脚本的 HTML 文件预览，不向任意外部网页注入脚本，也不支持浏览器内置 PDF 查看器。超过预览注入大小限制的 HTML 会提示标注不可用。iframe 继续使用独立的 sandbox origin；标注不会读取表单输入值，也不会把文件路径或认证 token 发给 iframe。元素定位取自当前页面状态，页面结构变化后可能失效。

原有文本选区引用与独立侧问保持独立，可以继续使用。

## 记忆来源

记忆中心展示可确认、更正、删除的记忆与来源入口。检索次数表示向任务提供过参考，不代表模型实际采用该记忆。自动记忆关闭时，仍可明确保存记忆；启用检索和自动学习需要完成引擎配置。实现与数据服务说明收在“记忆如何工作”中。

## 浏览器响应

设置 → 服务与诊断 → 浏览器响应展示当前页面的首次内容绘制、工作台就绪、长任务，以及最近 12 个已测回合的首段回复可见与最终结果可见耗时。

长任务观察器在浏览器空闲时加载，面板显示实际监测起点。回合可见耗时只计入当前会话、可见页面、视口中的对应消息节点；后台会话、没有绘制的结果或监测尚未开始的回合显示为未测得，不会冒充零耗时。回合耗时起点是本页开始建立该回合的流式连接，不包含此前在持久队列中的等待。

指标仅为当前页面内存中的数字，不上传会话正文、文件路径或请求 URL；刷新后重置。不同设备、标签页是否可见和网络情况会影响结果，不宜直接把它当作模型响应时间。

“流式队列状态”由服务提供队列深度、内存估计、最老事件等待与本次服务启动以来的溢出次数；旧版本服务未提供这些数据时会明确显示缺失。

Codex 额度刷新读取运行 MuseLab 主机上已登录的账户。未登录或登录失效时，请在该主机执行 `codex login`。Gateway 的认证不代表本机 Codex 已登录。刷新失败会明确提示；历史快照保留原时间并标注为历史数据，不代表当前剩余额度。刷新按钮等待用量与额度请求均结束后恢复。

更多工具、历史会话、打开文件列表与上下文详情等小型弹窗会跟随触发按钮，并适应分栏、屏幕旋转和可视区域变化。弹窗限制在所属面板内，避开手机底部导航；空间不足时换向展开并允许内部滚动。文件树下拉刷新复用刷新按钮的旋转动效，不再显示额外的状态条。
